# 04 — 配置是怎么工作的？

> 阅读时间：15 分钟 | 前置知识：[01](01_时钟是什么.md)、[02](02_时钟树与分频.md)

---

`clock_config.c` 是这个项目里最重要的配置文件——它决定整个芯片从哪个振荡器取时钟、跑多快、外设分到多少 MHz。但它由 NXP 工具自动生成，嵌套结构体 155 行，不知道在看什么很正常。

这篇文档把每一个配置块翻译成普通话。

---

## 1. 全局结构：一块大结构体，三个板块

```c
clock_manager_user_config_t clockMan1_InitConfig0 = {
    .scgConfig = { ... },   // 板块①: 选振荡器 + 系统分频 ← 最重要
    .pccConfig = { ... },   // 板块②: 外设各分配什么时钟       ← 你刚改的
    .simConfig = { ... },   // 板块③: 杂项 (RTC/调试/低功耗)   ← 不用管
};
```

加载过程：

```
Reset_Handler (汇编) → system_S32K144.c → CLOCK_DRV_Init(&clockMan1_InitConfig0)
                                                ↑
                                        就这一个结构体，把你刚才配的
                                        通通写进芯片寄存器
```

---

## 2. 板块① — `scgConfig`：振荡器 + 系统分频

### 2.1 `sircConfig` — SIRC（8MHz 内部 RC）

```
           ┌────────────┐
           │  SIRC 8MHz  │ ← 内部慢速 RC
           └──────┬─────┘
                  │ .div1=÷1 → SIRCDIV1 = 8MHz
                  │ .div2=÷1 → SIRCDIV2 = 8MHz
                  └── 你已不用，不用管
```

```c
.sircConfig = {
    .initialize       = true,                  // 初始化这个振荡器
    .enableInStop     = true,                  // STOP 模式下也跑
    .enableInLowPower = true,                  // 低功耗模式也跑
    .locked           = false,                 // 允许后续修改
    .range            = SCG_SIRC_RANGE_HIGH,   // 设为 8MHz (不是 2MHz)
    .div1             = SCG_ASYNC_CLOCK_DIV_BY_1,  // ÷1
    .div2             = SCG_ASYNC_CLOCK_DIV_BY_1,  // ÷1
},
```

| 你关心的 | 永远不动的 |
|----------|-----------|
| 无，已弃用 | 全部 |

---

### 2.2 `fircConfig` — FIRC（48MHz 内部 RC）⭐ 主角

```
           ┌──────────────┐
           │  FIRC 48MHz   │ ← 内部快速 RC，你的主时钟
           └───────┬──────┘
                   │ .div1=÷1 → FIRCDIV1 = 48MHz  → 喂 SCG（系统时钟）
                   │ .div2=÷1 → FIRCDIV2 = 48MHz  → 喂 PCC（外设时钟）
                   └── 都是 48MHz，不改
```

```c
.fircConfig = {
    .initialize       = true,                  // 初始化 FIRC
    .regulator        = true,                  // 内部稳压器开着
    .locked           = false,                 // 允许后续修改
    .range            = SCG_FIRC_RANGE_48M,    // ← 唯一能改的: 48M 还是 64M?
    .div1             = SCG_ASYNC_CLOCK_DIV_BY_1,  // FIRCDIV1 = 48/1
    .div2             = SCG_ASYNC_CLOCK_DIV_BY_1,  // FIRCDIV2 = 48/1
},
```

| 你关心的 | 永远不动的 |
|----------|-----------|
| `range = 48M` — 这是主频，S32K144 最大就 48MHz（你用 FIRC 的情况下） | `regulator`, `locked`, `div1`, `div2` |
| 如果想换 `FIRCDIV2` 的频率给 SPI/UART，改 `div2`（比如 `DIV_BY_2` = 24MHz） | |

---

### 2.3 `soscConfig` — SOSC（外部 8MHz 晶振）⭐ CAN 靠它

```
           ┌──────────────┐
           │ 外挂晶振 8MHz │ ← 板子上的小铁壳
           └───────┬──────┘
                   │ .div1=÷1 → SOSCDIV1 = 8MHz  → CAN PE 时钟
                   │ .div2=÷1 → SOSCDIV2 = 8MHz  → 备用 (PCC 可选)
                   └── CAN 通信必用这个
```

```c
.soscConfig = {
    .initialize       = true,                  // 初始化外部晶振
    .freq             = 8000000U,              // ← 你板上的晶振是 8MHz
    .monitorMode      = SCG_SOSC_MONITOR_DISABLE,  // 不监控晶振是否停振
    .locked           = false,                 // 允许修改
    .extRef           = SCG_SOSC_REF_OSC,      // 用的是石英晶振
    .gain             = SCG_SOSC_GAIN_LOW,     // 低增益模式
    .range            = SCG_SOSC_RANGE_HIGH,   // 高频晶振范围 (8-40MHz)
    .div1             = SCG_ASYNC_CLOCK_DIV_BY_1,
    .div2             = SCG_ASYNC_CLOCK_DIV_BY_1,
},
```

| 你关心的 | 永远不动的 |
|----------|-----------|
| `freq = 8000000` — 必须跟你板子上的晶振频率一致。买板子的时候厂家就配好了 | `extRef`, `gain`, `range`, `monitorMode` |

---

### 2.4 `spllConfig` — SPLL（倍频到 112MHz）

```c
.spllConfig = {
    .initialize       = true,
    .mult             = (uint8_t)SCG_SPLL_CLOCK_MULTIPLY_BY_28,  // 8M × 28 = 224M VCO
    .src              = 0U,                           // 源 = SOSC 8MHz
    .prediv           = (uint8_t)SCG_SPLL_CLOCK_PREDIV_BY_1,
    .div1             = SCG_ASYNC_CLOCK_DIV_BY_1,     // SPLL 输出 ≈ 112MHz
    ...
},
```

**你不需要懂**。SPLL 是 HSRUN（高速模式）用的。你现在 RUN 模式用 FIRC 48MHz，这东西虽然配置了但不会实际切过去。

| 你关心的 | 永远不动的 |
|----------|-----------|
| 无 | 全部 |

---

### 2.5 `clockModeConfig` — 选哪个振荡器当系统时钟 ⭐ 最重要

**这是整个文件里最关键的部分。**

```c
.clockModeConfig = {
    .initialize       = true,

    // RUN 模式 — 平时运行用的
    .rccrConfig = {
        .src     = SCG_SYSTEM_CLOCK_SRC_FIRC,   // ← 系统时钟用 FIRC (48MHz)
        .divCore = SCG_SYSTEM_CLOCK_DIV_BY_1,   // Core = 48 / 1 = 48MHz
        .divBus  = SCG_SYSTEM_CLOCK_DIV_BY_2,   // Bus  = 48 / 2 = 24MHz
        .divSlow = SCG_SYSTEM_CLOCK_DIV_BY_2,   // Slow = 48 / 2 = 24MHz
    },

    // VLPR 模式 — 低功耗
    .vccrConfig = {
        .src     = SCG_SYSTEM_CLOCK_SRC_SIRC,   // 低功耗用 SIRC 8MHz
        ...
    },

    // HSRUN 模式 — 高速 (不用)
    .hccrConfig = {
        .src     = SCG_SYSTEM_CLOCK_SRC_SYS_PLL,// 高速用 SPLL 112MHz
        ...
    },
},
```

**三种模式是互斥的：**

| 模式 | 时钟源 | Core 频率 | 就是你现在用的 |
|------|--------|----------|:---:|
| **RUN** | FIRC | 48 MHz | ✅ 是 |
| VLPR | SIRC | 4 MHz | ❌ 只有进低功耗才切 |
| HSRUN | SPLL | 112 MHz | ❌ 不用 |

**你能改的：**

```
.divCore = DIV_BY_1    → Core = 48 / 1 = 48MHz   ← CPU 速度
.divBus  = DIV_BY_2    → Bus  = 48 / 2 = 24MHz   ← 外设总线速度
.divSlow = DIV_BY_2    → Slow = 48 / 2 = 24MHz   ← Flash 速度
```

把 `DIV_BY_2` 改成 `DIV_BY_1` 就能让 Bus 也跑 48MHz——但别改，这是芯片手册规定的最大总线频率。

## 3. 板块② — `pccConfig`：外设时钟分发

这就是你刚改过的：

```c
.pccConfig = {
    .peripheralClocks = peripheralClockConfig0,  // 指向外设数组
    .count = NUM_OF_PERIPHERAL_CLOCKS_0,          // 共 20 个外设
},
```

`peripheralClockConfig0[]` 是一个**数组**，每一项代表一个外设的时钟配置：

```c
// 每项就 5 个字段
{
    .clockName = LPSPI0_CLK,           // 给谁？
    .clkGate   = true,                 // 开灯通电
    .clkSrc    = CLK_SRC_FIRCDIV2,     // 从哪取钟？
    .frac      = MULTIPLY_BY_ONE,      // 倍频 ×1
    .divider   = DIVIDE_BY_ONE,        // 分频 ÷1
},
// → LPSPI0 最终时钟 = FIRCDIV2(48MHz) × 1 ÷ 1 = 48MHz
```

**完整速查（你关心的 6 个）：**

| 项 | 外设 | clkSrc | 最终频率 | 你能改的 |
|----|------|--------|---------|----------|
| LPSPI0 | SPI0 | FIRCDIV2 | 48 MHz | divider（降速用） |
| LPSPI1 | SPI1 | FIRCDIV2 | 48 MHz | divider |
| LPSPI2 | SPI2 | FIRCDIV2 | 48 MHz | divider |
| LPUART0 | UART0 | FIRCDIV2 | 48 MHz | divider |
| LPUART1 | UART1 | FIRCDIV2 | 48 MHz | divider |
| LPUART2 | UART2 | FIRCDIV2 | 48 MHz | divider |
| FlexCAN0 | CAN0 | OFF | SOSC 8MHz | 不能在这改，CAN 用 PE 时钟 |
| PORTA~E | GPIO 端口 | OFF | — | 只是开闸通电 |

**你唯一可能改的：`divider`**

```
如果 SPI0 48MHz 太快（对端设备扛不住），把 divider 从 ÷1 改成 ÷2 或 ÷4
SPI0 实际时钟 = FIRCDIV2(48MHz) / divider
```

---

## 4. 板块③ — `simConfig`：杂项，不用管

```c
.simConfig = {
    .clockOutConfig   = { ... },  // CLKOUT 引脚输出 (调试用)
    .lpoClockConfig   = { ... },  // 低功耗时钟 (LPO 128KHz)
    .platGateConfig   = { ... },  // 平台级时钟门控 (MSCM/MPU/DMA)
    .traceClockConfig = { ... },  // 调试跟踪时钟
},
```

**全部不用管。** 能跑就行。

---

## 5. 一句话总结

| 你是谁 | 你关心里面的什么 | 你为什么要改 |
|--------|-----------------|-------------|
| **学 CAN/SPI/UART** | 板块② `pccConfig` → `peripheralClockConfig0[]` | 改 SPI/UART 时钟源 (SIRC→FIRC)、调分频比 |
| **调 CPU 主频** | 板块① `clockModeConfig.rccrConfig` | 改 Core/Bus/Slow 分频，切换 RUN/HSRUN 模式 |
| **换振荡器** | 板块① `fircConfig` / `soscConfig` | 改 FIRC 频率范围、晶振频率 |
| **只是学习** | 都不需要管 | 不动就跑得挺好 |

你现在的状态：**板块②刚改完（SIRC→FIRC），其他都是默认值，完美够用。**
